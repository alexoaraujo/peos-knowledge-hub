# Revisão de licenciamento pendente

Os três pacotes de origem não contêm licença explícita. A intenção de tornar o projeto open-source foi registrada, mas esta ausência **não concede automaticamente** permissão de redistribuição. Antes de oficializar uma licença para todo o repositório, confirmar titulares, fontes originais e termos dos conteúdos de terceiros. O código novo poderá receber licença aberta aprovada separadamente dos conteúdos originais, após confirmação.
