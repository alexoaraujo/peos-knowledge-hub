128. **Do conceito à produção**

> Transforme `[IDEIA]` em uma aplicação profissional pronta para produção.
>
> Execute sequencialmente:
>
> descoberta → requisitos → arquitetura → UX → UI → design system → banco de dados → backend → APIs → frontend → autenticação → autorização → segurança → testes → performance → infraestrutura → CI/CD → observabilidade → documentação → auditoria final → deploy.
>
> Em cada etapa:
>
> - preserve decisões válidas anteriores;
> - registre dependências;
> - identifique riscos;
> - valide o resultado;
> - somente avance quando a fundação necessária estiver consistente.
>
> O resultado final deve ser uma aplicação funcional, integrada, segura, testada, documentada, responsiva, acessível e preparada para produção.
