# Contribuindo

Abra um issue para alteração editorial, novo prompt ou melhoria. Um PR precisa identificar motivo, impacto, ID permanente, referência da fonte, versão, hash, testes, riscos e rollback. Não editar manualmente arquivos derivados (`hub-portal/catalog.json`, índices compilados) sem executar o gerador. Novos PMUs permanecem `PROPOSED` até revisão. Não incluir segredos, documentos internos ou conteúdo sem direitos de redistribuição. Consulte `docs/HUB_GOVERNANCE.md`.
